# Echo acquisition evidence

Each new phone recording may include `acquisition` version 1. It records what the browser requested, the settings the browser reports for the audio track, the software schedule used for the probe, and input-continuity counters when the AudioWorklet can observe them. It improves provenance; it does not calibrate the microphone or validate room geometry.

## Evidence fields

- `requested` records the three requested media constraints: echo cancellation, noise suppression, and automatic gain control. They are requests, not proof that the full device or operating system processing path is disabled.
- `applied` contains only allowlisted values reported by the browser for the media track: those three booleans, sample rate, channel count, sample size, and latency when available. Device and group identifiers are rejected.
- `timing` uses the AudioContext software frame clock. AudioWorklet captures use `precision: "sample-frame"` and an absolute context `captureStartFrame`; the compatibility recorder uses `precision: "approximate"` and `captureStartFrame: null`. Both record the scheduled chirp frame and its 80 ms length.
- `continuity` is either `status: "observed"` with frame counts or `status: "unavailable"`. Observed counts distinguish frames with input, frames without input, and frames whose callback interval was unobserved. `presentZeroFrames` and `longestPresentZeroRunFrames` count exact zero samples within present input. All counts are frames; the three coverage counts sum to `captureFrames`.

The scheduled chirp frame describes when playback was requested on the software clock. In repeated-probe mode, the same AudioContext clock has a 1 s warmup target, then schedules five distinct 700 ms PCM windows at least 1 s apart. The first probe waits until the target is reached; if the context is delayed, it starts later. An interrupted warmup may produce a shorter partial manifest with no captured probes. This is not the actual acoustic emission time, a verified arrival, or a direct-sound reference. Analysis intervals remain sample-relative to the start of each saved PCM. Keep those absolute intervals and any comparison-reference-relative delays separate in reports.

If an old scan has no acquisition object, its continuity and settings are unknown. Do not fill missing metadata with zeros or infer input gaps from preallocated PCM zeros. A present zero-valued frame is distinct from a missing input frame, and both are distinct from an interval the recorder could not observe.

## Capture sequence

ECHO-02 and ECHO-03 acquisition, validation, relay transport, scan migration, review display and offline report are implemented in software. The 338 Vitest checks, 22 relay/helper tests, 14 tooling tests, full typecheck, build, security/offline checks and 14 focused Chromium checks passed, including three repeated-series browser cases. One real Android five-probe batch now has complete observed input in all five 700 ms windows, no clipped samples and no PCM zero runs ≥5 ms. The first strongest reference is 6 ms earlier than the other four; it remains in the evidence. This exercises the series/telemetry path without validating acoustic timing or identifying a wall. The batch owns one microphone stream and AudioContext for its warmup and five probes. A partial batch preserves completed probe samples and marks all five attempts as captured, interrupted, or not started. Page hide/exit, track end, and context stop cancel the batch; the microphone stops before review or send. The next physical gate is the controlled ECHO-04 single-wall test; no arbitrary room scan is requested.

For a controlled physical ECHO-04 session, test one clear hard wall after documenting the physical setup. State the hypothesis first: the same repeatable candidate track should shift later by about 5.83 ms for each additional metre of perpendicular phone-to-wall distance. Keep phone height, orientation, heading, speaker volume report, axes, phone, built-in speaker/microphone, and nearby-body placement fixed; vary only perpendicular distance in measured 0.5 m steps at three or more distances. Collect five probes per pose. Stop if the wall track cannot be identified consistently, a matched probe window has missing input, any requested pose cannot be measured safely, or three distances with repeats have been collected. This protocol is actionable guidance only; no capture is requested here.

The worklet path classifies input per rendered frame and preserves the original PCM, including zeros in missing or unobserved intervals. The compatibility recorder cannot reliably classify frame continuity, so it reports continuity as unavailable. Neither path repairs, interpolates, or compresses the saved samples.
